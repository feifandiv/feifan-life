# 安装与使用

当前界面为中文，仅支持桌面端 Obsidian 1.14.5 及以上；原生验收环境为 macOS，Windows 与 Linux 尚未完成原生验收。公开版标识 `feifan-life`，不自动导入作者版或其他插件的数据。

## 安装

尚未进入 Obsidian 官方社区目录，不能在目录内搜索安装。仓库发布 Release 后，从该版本的 Assets 下载三个独立附件：`main.js`、`manifest.json`、`styles.css`。GitHub 的 Source code 压缩包不是可直接安装包。

1. 先备份知识库，首次体验可使用独立空白知识库。
2. 在当前知识库的实际配置目录下建立 `plugins/feifan-life/`。默认配置目录通常为 `.obsidian`；自定义配置目录时使用实际名称。
3. 把上述三个附件放入 `feifan-life` 文件夹，避免多套一层文件夹。
4. 在 Obsidian 设置 → 第三方插件中允许使用第三方插件，重新加载并启用 Feifan Life。
5. 点击侧边栏命令图标，或在命令面板运行“非凡人生”打开工作区。

发布前开发者可按 [README](../README.md#build-and-check) 自行构建，安装 `build/` 中的三个文件。当前尚无可下载的官方 Release，不提供假下载链接。

## 初次使用

| 模块 | 起步动作 |
|---|---|
| 总览 | 查看今日信息与模块入口 |
| 任务 | 在项目看板创建项目，或直接新建零散任务 |
| 规划 | 新建年度目标或愿景，填写指标与条件 |
| 财务 | 先设置分类，再记录收入、支出；确认个人或生意账本 |
| 清单 | 添加阅读、观影、学习记录及物资 |
| 习惯 | 添加习惯、频次与单位，再进行打卡 |
| 灵感 | 新建灵感并整理状态与标签 |
| 复盘 | 点击新建复盘；保存为知识库内普通日期 Markdown |

点击导航栏齿轮修改称呼、问候语、背景及显示模式。三张默认背景离线可用。天气默认关闭，复盘未配置目录前不会自动读取笔记。

当前版本没有收费、账号、AI 或额度拦截；日后的商业方案不代表本版本已有这些功能。

## 更新、备份与卸载

- 更新前备份知识库，关闭插件，用同一插件 ID 的新版本三个附件替换旧代码，再启用。保留 `data.json` 和 `backups/`，不要用别人提供的运行数据覆盖它们。
- 记录及设置保存在 `<配置目录>/plugins/feifan-life/data.json`，自动备份位于同目录 `backups/`。复盘及主动同步的任务 Markdown 保存在用户所选目录。
- 自动备份与主数据同处一个插件目录，不能替代独立备份。定期把知识库及配置目录复制到其他位置。
- 自动写入前备份最多保留最近 30 份；每天首次加载的日度备份没有自动到期清理。损坏原文件副本在 `backups/invalid/` 保留。这些副本与原数据处于同一磁盘，磁盘故障时无法提供独立保护。
- 恢复前完全关闭插件或退出 Obsidian，保留当前数据副本，再使用经校验的备份；不要在插件运行时外部覆盖内存中的数据。更早版本是否能读取新结构需单独核对，不能只换旧代码强行降级。
- 先禁用插件即可停止使用；删除插件目录也会删除其中的主数据和自动备份。卸载前导出或复制数据。普通复盘和任务镜像不会因删代码而自动删除。

## 遇到问题

从仓库的 Issues 提交问题，附操作步骤、插件版本、Obsidian 版本和系统。截图遮盖隐私，不上传整个知识库、`data.json`、备份或密钥。安全问题遵循 [安全反馈说明](../SECURITY.md)。
