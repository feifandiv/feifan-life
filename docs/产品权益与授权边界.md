# 产品权益与授权边界

更新日期：2026-11-02。

本文件区分已确认的产品原则与尚未实施的系统。当前插件不含账户、容量限制、付款、授权验证或 AI 计费。作者要求宽松免费额度、AI 及商业接入暂缓；具体建议为 30 个进行中项目、500 条未完成任务、每月 1,000 笔账单与 ¥99 一次性支持版，仍待评审，完整定义见 [免费额度与支持版方案](免费额度与支持版方案.md)。

## 已确认的原则

1. 基础版在公开额度内永久免费，没有试用到期日。
2. 项目按同时进行中的数量计数，任务按未完成数量计数；完成、正常归档后释放相应额度，不按终身累计创建数限制。
3. 超出额度只影响新的创建操作；已有记录仍可查看、编辑、完成、归档和导出。
4. 不因账单超过一年而禁止持续记账，不自动删除历史记录，不通过锁住已有数据要求付款。
5. 可一次性付费解锁约定的本地容量限制。具体适用版本、设备范围和未来更新承诺在正式销售前明确。
6. AI 服务单独按积分收费，买断不代表无限 AI。免费版和买断版均可按未来的 AI 使用规则购买积分。
7. 免费本地功能不强制注册，不为验证授权而上传笔记、任务或账目。

## 购买与激活流程

安装插件 → 免费使用 → 查看额度与升级 → 外部购买页 → 支付渠道通知服务端 → 服务端核实订单 → 账号领取授权或激活码 → 插件验证并缓存权益。

- 不能把购买页显示“成功”当作到账依据。服务端验证支付回调签名、订单金额、币种和商品，并以订单标识保证重复回调只发放一次权益。
- 产品账号与 Obsidian 账号独立。账号找回、换设备、退款和授权撤销的规则在上线前明确。
- 授权私钥只存在服务端。客户端可持公钥和可公开的产品标识；删去密钥文件或使用 `.gitignore` 不能清除已经提交过的秘密。
- 买断本地能力支持离线使用，必须明确离线凭证的有效期与撤销策略。若设计成永久离线凭证，就不能承诺即时远程撤销。
- AI 请求由服务端检查权益、结算积分并保存必要的计费记录。失败、取消、重试的扣费方式需单独定义；不把模型 API 密钥发给插件。

## 开源与商业权益

公开客户端源码包括额度展示、升级入口、授权验证和 AI 调用的客户端部分。用户可按最终开源许可证修改及重新分发；本地额度限制不能视为不可绕过的安全保障。

支付、订单、授权签发、AI 网关和积分账本未来放在独立私有服务工程。商业价值包括官方版本、持续维护、支持服务与服务端能力。作者已选择客户端 GPL-3.0-only，完整条款见根目录 LICENSE；第三方素材按各自许可。不能把“只允许付费用户修改”当作标准开源许可。

## GitHub 与 Obsidian 展示

README、购买页、插件内权益页应保持一致，公开免费额度、计数规则、付费权益、联网服务及隐私说明。功能限制和付费服务上线后，社区目录通常应标注 Optional payment；如果免费容量实际上构成有限试用，则不能用“永久基础版”误导用户。
