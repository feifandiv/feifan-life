# 非凡人生 / Feifan Life 0.2.0

首个独立免费版本，供桌面端试用与反馈。当前界面为中文，支持 Obsidian 1.14.5 及以上；原生验收环境为 macOS，Windows 和 Linux 尚未完成原生验收。

## 功能

- 总览、项目与任务、年度规划、双账本财务、清单、习惯、灵感和复盘。
- 自定义称呼、问候语、目录、背景与深浅模式。
- 三张随安装包提供的离线背景图。
- 新建日期复盘 Markdown；已有同日期笔记不覆盖。
- 空白安装，不包含作者笔记、任务或账目；不自动读取其他插件的数据。
- 所有现有本地功能免费，无账号、额度限制、支付或 AI。

## 安装与数据

下载下方 Assets 的 `main.js`、`manifest.json`、`styles.css`，放入测试知识库实际配置目录下的 `plugins/feifan-life/`，在第三方插件设置启用。Source code 压缩包是源码，不能直接作为插件安装。

记录及设置保存在插件目录的 `data.json`；自动备份也在插件目录，卸载前务必做独立备份。普通复盘与任务 Markdown 在用户指定目录。优先在空白知识库体验，不导入个人自用插件的数据。

天气默认关闭；启用后调用 Open-Meteo 的地名与天气接口。任务、账目和笔记不会由该功能发送。更多说明见仓库的 README、PRIVACY.md、安装说明与验收记录。

## 已知范围

- 不声明兼容早于 1.14.5 的 Obsidian 或移动端。
- 模拟宿主测试与浏览器展示图不能证明所有原生交互；代表性大数据量的性能尚未测量。
- 问题反馈使用虚构数据，勿提交完整知识库、账目、备份或密钥。安全问题先阅读 SECURITY.md。
