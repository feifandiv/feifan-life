# 非凡人生 / Feifan Life 0.2.1

修复总览与右侧「今日聚焦」不一致，以及时间百分比容易被误认为任务进度的问题。

## 本次更新

- 总览与右栏共用手动加入的聚焦任务和子项，统一排序、完成状态与计数。到期、逾期任务不再自动混入聚焦列表。
- 未完成项优先，按 P0–P3 排序，已完成项沉底；过滤重复、已删除及已归档记录。
- 两处都能勾选完成、移出聚焦、原地打开任务详情；打开子项时直接定位对应输入框。
- 卡片、任务汇总、日历和聚焦完成率统一采用已完成/总数。
- 「今年进度 / 本月进度」改为「今年时间已过 / 本月时间已过」，与聚焦完成率分开；修正时间多计一天及年末超出 100% 的问题。
- 详情保存成功后才关闭；失败保留表单供重试。量化目标自然达标时保留已记录数量，通过详情修改。

## 更新与安装

退出或禁用 Feifan Life，备份当前插件目录的 data.json 及 backups，再用 Assets 中的 main.js、manifest.json、styles.css 替换同名程序文件，重新启用插件。不要删除或替换自己的 data.json 和 backups；不需要迁移数据。

首次安装时，将三个程序文件放入知识库实际配置目录下的 plugins/feifan-life/，再在第三方插件设置启用。GitHub 自动生成的 Source code 压缩包是源码。

## 验证范围

28 项自动测试、类型检查、构建、许可清单和安装包完整性检查通过。聚焦同步、勾选/取消、详情保存、子项初始光标及插件重载数据保留已在 macOS / Obsidian 1.15.0 原生检查。要求 Obsidian 1.14.5 及以上，仅支持桌面端；Windows、Linux、最低版本重新验收与大数据量性能仍未完成。
