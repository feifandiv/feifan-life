# 普适化改造说明

本工程从已有客户端代码建立独立副本。仅纳入正式源码、构建配置和必要设计规范，不纳入业务数据、个人笔记、工作台快照、历史截图、旧代码备份、私人部署脚本和内部策略书。

## 已改造内容

| 范围 | 处理 |
|---|---|
| 插件与视图 | 使用独立标识 `feifan-life`、`feifan-life-view` |
| 存储 | 按当前知识库 `configDir` 和插件标识生成数据与备份路径，不访问其他版本数据 |
| 首次启动 | 各模块使用有效的空数据结构，不依赖作者已存在的数据 |
| 个人记录 | 不附带任务、项目、账目、目标、习惯或个人平台用量种子 |
| 个性化 | 提供称呼、问候语、主题、背景图片、天气、城市、复盘及镜像目录设置 |
| 背景素材 | 内置三张有 CC0 来源记录的照片，离线可用并默认启用湖畔森林；支持自定义知识库图片 |
| 天气 | 默认关闭，无预设个人城市；主动启用后联网 |
| 复盘 | 默认无目录；新建弹窗可保存标准 Markdown 并记住目录，已有同日文件不覆盖；仅在指定目录内发现复盘 |
| 构建 | 只输出三个安装文件，无现用版部署脚本或本机目标路径 |
| 验证 | 空白启动、存储隔离、任务重载、保存失败、备份恢复及个性化渲染的自动检查 |

## 维护方式

本副本是普适化产品的开发入口。修复公共问题时先在本副本验证，再以明确的代码变更同步到个人使用环境；不要把运行目录或数据文件反向复制进源码。公开工程只用合成测试数据。

测试使用模拟的 Obsidian API 和内存数据适配器。自动检查不能代替真实 Obsidian 中的安装、兼容、深浅模式和窗口交互验收；完整发布条件见 [发布准备清单](发布准备清单.md)。
